# Persona identity

Slogan: **Become more you.**

- `logo.svg`: editable white masquerade mask with a blue brow and central diamond on black, drawn as vectors.
- `icon.png`, `favicon.png`: deterministic raster exports of the vector mark; regenerate with `node scripts/brand.mjs`.
- `hero.png`: generated with the built-in imagegen tool, saved inside this project and used in the dashboard.

> Use case: stylized-concept. Wide landscape composition. No text, no letters, no watermark.

Palette: black canvas `#08090B`, charcoal surfaces `#111318`, white text `#F5F6F8`, blue accents `#6191FF`, blue buttons `#285FE0`.
